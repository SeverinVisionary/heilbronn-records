# gh-pages — the documentation landing page

Serves https://severinvisionary.github.io/heilbronn-records/ — the landing page
for DOI 10.5281/zenodo.22091169, carrying Google Scholar `citation_*`, Dublin
Core, Open Graph and schema.org `Dataset` metadata. Also serves
`heilbronn-disk-n14-note.pdf`, named by the page's `citation_pdf_url` tag so
that Google Scholar has a full-text document to index: `disk/NOTE.md` as it
stands on `main` at c06bdb5, typeset with only a title block added.

It is on an orphan branch so that `main` stays exactly the tree the deposit was
cut from. It states no claim that is not already in `README.md` and
`disk/NOTE.md` on `main`, including the two retractions and the explicit
"best value we could locate, not a proved record" scoping.
